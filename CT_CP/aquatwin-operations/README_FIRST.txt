AQUATWIN CONTROL PANEL — REFERENCE PACK

WHAT IS INCLUDED
- public/reference-images/control-panel/01-current-control-panel.png
  Screenshot of your current Control Panel (the version Claude Code has already made).
- public/reference-images/control-panel/02-desired-control-panel-layout.png
  Full-page visual direction for the desired Control Panel layout.
- public/reference-images/control-panel/03-desired-cabinet-closeup.png
  Close-up of the realistic industrial electrical cabinet to guide the main visual.
- CLAUDE_CODE_PROMPT.txt
  Ready-to-paste instructions for Claude Code.

HOW TO INSTALL
1. Extract this ZIP directly into the root of your existing aquatwin-operations project folder.
   The folder containing package.json should be the extraction destination.
2. Allow Windows to merge the included public folder if prompted. These files are additions under
   public/reference-images/control-panel; do not replace your source code.
3. Open Claude Code in the aquatwin-operations project root.
4. Paste the contents of CLAUDE_CODE_PROMPT.txt into Claude Code.

IMPORTANT
The images are visual references. The desired cabinet image is not a real PLC panel and must not
be presented as proof of physical hardware connectivity. Keep all plant/PLC data simulated unless
actual hardware integration already exists.
